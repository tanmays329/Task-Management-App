# TaskFlow - Task Management Web Application

TaskFlow is a full-stack task management application that helps users organize and manage their daily tasks. It provides secure authentication, task management, due dates, pagination, and a responsive user interface.

## Live Demo

Frontend: https://task-management-app-rho-fawn.vercel.app/

Backend: https://task-management-app-jvb6.onrender.com/

---

## Features

- User Registration and Login
- JWT Authentication
- Create, Read, Update, and Delete Tasks
- Task Status Management
- Due Date Support
- Pagination
- Responsive UI
- Toast Notifications
- Loading Spinner
